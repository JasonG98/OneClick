# Simplify：减少开发维护负担

精简 CI/CD、脚本与文档。保留 Finder 工具的核心功能和进程边界。

## 最终范围

- 删除图标生成器及其测试；现有图标原样移入 `assets/Assets.xcassets`。
- 脚本收成五个：`build_and_run.sh`、`check.sh`、`generate_project.py`、`release.py`、`uninstall.sh`。
- 构建默认完成启动验证，只保留 `--build-only`；测试保持一个入口，不增加模式矩阵。
- 打包、校验和、Cask、草稿上传合并到 `release.py`，删除共享 shell 库和多层包装。
- CI 保留检查与发布两个 workflow；发布用单个任务完成，去掉跨任务产物转移。
- 卸载只处理当前应用与数据，保留归属保护和默认预览，删除历史扫描与仓库清理选项。
- 重写 README 和开发文档；旧实施与桌面证据归档，当前说明保持简短。

## 验收

脚本替身测试、Swift 测试、应用与扩展编译、本地 Release 打包、工程重复生成与静态图标一致性。
真实 Finder、下载隔离及远程发布只按实际观察记录，不以本地检查替代。
结果见[实施记录](../../implementation-log.md)。
